# Web Project Landing Page

This repository contains a clean, modular single-page landing page setup.

## Project Structure

```text
landing-page/
├── index.html
├── styles.css
└── README.md
```

## Features
- Modular structure (HTML, CSS separated)
- CSS custom properties for styling and dark mode preference support
- Fully responsive grid and flexbox layout
- Ready for deployment or integration into static site hosting (GitHub Pages, Vercel, Netlify)
